= What's new in ONTAP tools for VMware vSphere 10.6
:icons: font
:imagesdir: ../media/

[.lead]
ONTAP tools for VMware vSphere 10.6 introduces enhancements for protection, auditing, scalability, and lifecycle operations.

== Granular datastore protection

ONTAP tools 10.6 introduces datastore-level protection, so you can protect only the datastores you select instead of applying protection only at the host-cluster level.

Key enhancements include:

* Datastore-level protection for ONTAP platforms and ASA r2 systems
* Automated Failover Duplex (AFD) and asynchronous protection policies
* Support for iSCSI and FC VMFS datastores
* Hierarchical consistency groups and fan-out configurations
* Uniform and non-uniform AFD protection configurations
* Ability to modify protection by adding or removing datastores and hosts
* Native datastore protection workflow from the vCenter plug-in
* Upgrade path from existing host-cluster protection to datastore-level protection

== Audit logging

ONTAP tools 10.6 adds comprehensive audit logging as part of secure-by-design improvements.

Audit logging includes:

* All non-GET REST API calls, including request and response details
* Discovery jobs, AutoSupport bundle jobs, cleanup jobs, and maintenance console operations
* Integrity protection for audit log archives, including tamper and delete alerts
* Syslog forwarding support

These updates improve traceability and help with compliance and security requirements.

== nConnect support for NFS datastores

ONTAP tools 10.6 adds nConnect support for VMware NFS datastores, enabling multiple parallel TCP connections between ESXi hosts and ONTAP NFS datastores. It supports:

* nConnect for NFSv3 datastores during provisioning
* nConnect for NFSv4.1 datastores during provisioning with vCenter 8.0U3 and later

This improves I/O parallelism and helps increase NFS datastore performance for multi-VM workloads.

== Start small and scale with extra-small deployment

ONTAP tools 10.6 introduces a smaller default extra-small (XS) deployment profile to reduce resource overhead and simplify day-0 deployment.

Enhancements include:

* XS as the default configuration for day-0 deployment
* Support for datastore provisioning, protection, SRA service enablement, and HA mode with XS
* Four available deployment profiles in the Manager UI: XS, S, M, and L

This model provides a lower starting footprint with a clear scale-up path as your environment grows.

== Protection workflow improvement

ONTAP tools 10.6 removes the requirement to manually trigger storage discovery when ONTAP clusters are unavailable, simplifying protection workflows.

== Supportability enhancements

ONTAP tools 10.6 improves troubleshooting and lifecycle management. Key updates include:

* Force delete for unreachable or stale vCenter entries
* Migration from `ntpd` to `chronyd` for time synchronization, with automatic migration of existing NTP server settings during upgrade
* Support for both traditional NTP servers and RHEL-based chrony servers over standard NTP protocol (UDP port 123)

For the latest details on version compatibility, refer to https://mysupport.netapp.com/matrix[NetApp Interoperability Matrix Tool^].
