= Clean up VASA configurations after deleting virtual machines
:icons: font
:imagesdir: ../media/

[.lead]
Follow these steps to complete VASA cleanup in ONTAP tools.
[NOTE]
Remove any vVols datastores before you start VASA cleanup.

.Steps

. Open `\https://OTV_IP:8143/Register.html` to unregister the plug-in.
. Verify that the plug-in is no longer available on the vCenter Server.
. Shut down the ONTAP tools for VMware vSphere virtual machine (VM).
. Delete ONTAP tools for VMware vSphere VM.
