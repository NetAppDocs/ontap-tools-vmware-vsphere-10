= View virtual machine storage details in ONTAP tools
:icons: font
:imagesdir: ../media/

[.lead]
Use the storage view to see the vVols associated with a virtual machine. 

NOTE: This view applies to VMs with at least one disk from an ONTAP tools for VMware vSphere managed vVols datastore.

.Steps

. From the vSphere Client go to the virtual machine.
. Select the *Monitor* tab in the right pane. 
. Select *NetApp ONTAP tools* > *Storage*. The *Storage* details appear on the right pane. You can see the list of vVols on the VM.
+
You can use the *Manage Columns* option to hide or show columns.
