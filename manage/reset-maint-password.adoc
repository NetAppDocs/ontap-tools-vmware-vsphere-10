= Reset the ONTAP tools maintenance console password
:icons: font
:imagesdir: ../media/

[.lead]
During a guest OS restart, the GRUB menu displays an option to reset the maintenance console user password. 
Use this option to update the password on the VM. After you reset the password, the VM restarts. In an HA deployment, the system automatically updates the password on the other two VMs after the restart.

[NOTE]
For an ONTAP tools for VMware vSphere HA deployment, change the maintenance console user password on the ONTAP tools management node (node1).

.Steps

. Log in to your vCenter Server
. Right-click the VM and select *Power* > *Restart Guest OS*. 
During system restart, the following screen appears:
image:../media/maint-console-password.png[Reset maintenance user's password]
+
You have five seconds to choose an option. Press any key to stop the countdown and pause the GRUB menu.
. Select *Reset maintenance user's password* option. The maintenance console opens.
. In the console, enter and confirm the new password. You have three attempts. The system restarts after you successfully enter the new password.
. Press *Enter* to continue.
The system updates the password on the VM.

[NOTE]
The same GRUB menu appears when you power on the virtual machine. Use the reset password option only with *Restart Guest OS*.
