= Manage storage thresholds in ONTAP tools
:icons: font
:imagesdir: ../media/

[.lead]
You can set storage thresholds to receive notifications in vCenter Server when volume or aggregate capacity reaches a certain level.

.Steps

. Log in to the vSphere Client.
. On the *Shortcuts* page, select *NetApp ONTAP tools* in the *Plug-ins* section.
. In the left pane of ONTAP tools, go to *Settings* > *Threshold Settings* > *Edit*.
. In the *Edit Threshold* window, provide the desired values in the *Nearly Full* and *Full* fields and select *Save*.
+
[NOTE]
You can restore the threshold values to the recommended defaults: 80 for Nearly Full and 90 for Full.
