= Manage audit logs for ONTAP tools
:icons: font
:imagesdir: ../media/

[.lead]
ONTAP tools for VMware vSphere 10.6 includes audit logging to support security, governance, and compliance requirements. Audit logs provide an event trail that shows who performed an action, what action was performed, when it occurred, and whether it succeeded or failed.

Audit logging supports forensic investigations and operational accountability across ONTAP tools Manager UI activity, REST API activity, scheduled jobs, and maintenance console activity.

== What ONTAP tools captures in audit logs

ONTAP tools generates audit events for the following operations:

* External REST API operations
** All non-GET REST API requests are audited, such as POST, PATCH, PUT, and DELETE.
** GET requests are not audited.
* Key internal system activities
** Discovery jobs
** AutoSupport (ASUP) bundle generation jobs
** Cleanup jobs
* Maintenance console activities
** Maintenance console operations are captured in a separate audit log.

== Audit event fields

Audit records include a consistent set of fields to support traceability. Typical fields include:

* Timestamp (UTC)
* Username (authenticated user identity)
* Operation (HTTP method and request URI)
* Status (success or failure and status code)
* User agent (client identity, if available)
* Request identifier, when available (for example, correlation ID)
* Job identifier, when available (for asynchronous workflows)
* Tenant or vCenter identifier, when available

[NOTE]
Depending on the operation, request and response details might be included. To reduce the risk of sensitive data exposure and control log growth, captured payloads can be truncated and secrets are redacted.

== Example audit record

The following example shows the type of information captured. The exact field set can vary by workflow.

[source,json]
----
{
  "timestamp": "2026-01-29T08:21:51Z",
  "username": "administrator",
  "operation": "POST /virtualization/api/v1/vcenters/{vcguid}/traditional/datastores",
  "status": "Success 202",
  "user_agent": "Mozilla/5.0 ...",
  "correlation_id": "9ee9a89e-900d-4538-bcab-79830d4ab7cc",
  "job_id": "3416",
  "type": "audit"
}
----

== Sensitive data handling

Audit logs support investigations without exposing secrets.

* Sensitive data, such as passwords, tokens, and private key material, is redacted.
* Long request and response payloads might be truncated.

== Limitations

* GET REST API calls are not captured in the audit log.
* Disabling audit logging is not supported.
* Audit log file size is not user-configurable.

== Audit log rotation and retention

* Audit logs rotate daily.
* The default retention period is 30 days.
* You can configure the retention period through the ONTAP tools maintenance console, or through the supported ONTAP tools configuration mechanism for your deployment.

[IMPORTANT]
If you have long-term retention requirements, such as regulatory retention, forward audit logs to an external syslog or SIEM destination and manage retention externally.

== Audit log integrity monitoring

ONTAP tools monitors archived audit logs for deletion or tampering.

* Integrity verification runs at a regular interval, for example every 24 hours.
* If ONTAP tools detects tampering or deletion of an archived audit log, it raises an alert in ONTAP tools Manager.

== If an integrity alert occurs

If ONTAP tools reports an audit log integrity alert:

. Collect a support bundle as soon as possible.
. Preserve relevant exported bundles and archives according to your organization's incident response process.
. Review the alert details in ONTAP tools Manager and contact NetApp Support if required.

== Forward audit logs to syslog (optional)

ONTAP tools supports forwarding audit logs to an external syslog server, for example for centralized monitoring or SIEM integration.

Use syslog forwarding when you require:

* Centralized log collection across environments
* Long-term retention beyond local default retention
* Correlation with other infrastructure audit events

Refer to your organization's syslog and SIEM standards for TLS, certificates, ports, and retention policies.

== Where to access audit logs

Audit logs are included in ONTAP tools log bundles (support bundles).

To collect audit logs, follow the standard procedure in the topic for collecting log files and support bundles, and provide the bundle to NetApp Support when requested.
