= Manage protection groups in ONTAP tools
:icons: font
:imagesdir: ../media/

[.lead]
View, edit, and remove protection groups and their relationships directly from the cluster configuration page.

.Before you begin

Ensure you have administrative privileges in vSphere.

.Steps

. In the ONTAP tools plugin, navigate *Protection* > *Host proximity/access*.
. To edit a group, select the group and click Edit. Update relationships as needed.
. To remove a group, select the group and click Remove. Confirm the deletion.
. To add or remove relationships, use the options available on the cluster configuration page.

[NOTE]
The warning message for deleting target artifacts during unprotect operations remains unchanged.

.Result
Protection groups and relationships are managed directly from the configuration page, streamlining the workflow.
