= Change ONTAP tools Manager password
:icons: font
:imagesdir: ../media/

[.lead]
You can change the administrator password in ONTAP tools Manager.

.Steps

. Launch ONTAP tools Manager from a web browser: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/` 
. Log in with your ONTAP tools for VMware vSphere administrator credentials.
. Select the *administrator* icon in the upper-right corner and select *Change password*.
. In the *Change password* dialog box, enter the old and new passwords. Review the password requirements shown there.
. Select *Change* to apply the changes.
