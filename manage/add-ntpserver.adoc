= Add NTP servers to ONTAP tools
:icons: font
:imagesdir: ../media/

[.lead]
Enter NTP server details to synchronize the ONTAP tools appliance clocks.

[NOTE]
Beginning with ONTAP tools for VMware vSphere 10.6, the time synchronization daemon is chronyd instead of ntpd. During an upgrade to 10.6, existing NTP server settings are automatically migrated. No manual reconfiguration is required.

//10.6 updates chronyd updates

.Steps

. Launch ONTAP tools Manager from a web browser: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/` 
. Log in with the ONTAP tools for VMware vSphere administrator credentials you provided during deployment. 
. Select the *Settings* > *NTP server* > *Edit* option.
. Enter the comma-separated fully qualified domain names (FQDNs) or IPv4 addresses.
+
Refresh the screen to see the updated values.
