= Update vCenter Server credentials in ONTAP tools
:icons: font
:imagesdir: ../media/

[.lead]
Use the maintenance console to update the vCenter Server instance credentials.

.Before you begin

You need maintenance user credentials.

.About this task

If you changed vCenter Server credentials after deployment, update them using this procedure.

.Steps

. Log in to the vCenter Server.
. Locate the ONTAP tools VM and launch the web console.
. Log in using the `maint` credentials.
. Enter `2` to select System Configuration Menu.
. Enter `8` to change vCenter credentials.
