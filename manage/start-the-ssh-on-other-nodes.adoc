= Start SSH on other ONTAP tools nodes
:icons: font
:imagesdir: ../media/

[.lead]
Before you upgrade ONTAP tools for VMware vSphere, you need to start SSH on each of the other nodes in your environment.

.Before you begin

Enable the VASA Provider extension for your vCenter Server instance.

.About this task

Repeat this procedure on each node before upgrading.

.Steps

. Log in to the vCenter Server.
. Locate the ONTAP tools node VM and launch the web console.
. Log in using the `maint` credentials.
. Enter `4` to select Support and Diagnostics.
. Enter `1` to select Access diagnostic shell.
. Enter `y` to proceed.
. Run the command _sudo systemctl restart ssh_.
