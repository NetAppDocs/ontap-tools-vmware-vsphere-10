= Enable ONTAP tools services
:icons: font
:imagesdir: ../media/

[.lead]
Use ONTAP tools Manager to enable optional services such as VASA Provider, vVols configuration import, and disaster recovery (SRA).

.Steps

. Launch ONTAP tools Manager from a web browser: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/` 
. Log in with the ONTAP tools for VMware vSphere administrator credentials you provided during deployment.
. In the *Overview* section, select *Edit Appliance Settings*.
. In the *Services* section, enable the optional services you need, such as VASA Provider, vVols configuration import, and disaster recovery (SRA).
+
When you enable these services for the first time, create VASA Provider and SRA credentials.

* Use these credentials to register and enable VASA Provider and SRA services on vCenter Server.
* The username can contain only letters, numbers, and underscores.
* The password length must be between 8 and 256 characters.

[NOTE]
Before you disable any optional service, ensure that vCenter Server instances managed by ONTAP tools do not use that service.
+
The *Allow import of vVols configuration* option appears only when the VASA Provider service is enabled. This option enables vVols data migration from ONTAP tools 9.x to ONTAP tools 10.6.
