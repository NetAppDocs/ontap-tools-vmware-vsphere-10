= Scale up ONTAP tools and enable High Availability
:icons: font
:imagesdir: ../media/

[.lead]
Use ONTAP tools Manager to scale up the appliance or configure High Availability (HA). By default, ONTAP tools for VMware vSphere deploys as a single-node, non-HA configuration.
// OTVDOC-256 jira updated note removed for JIRA OTVDOC-290

.Before you begin

* Ensure that your OVA template matches the version of Node 1 (the initial deployment node).
* Enable CPU hot add and memory hot plug on the hypervisor. These features are required to scale up the appliance and enable HA. For ONTAP tools 10.6 and later, these features are enabled by default. For earlier versions, enable these features before scaling up or enabling HA.
* In vCenter Server, set the Disaster Recovery Service (DRS) automation level to partially automated. Revert to fully automated after HA deployment completes.
[NOTE]
You can only increase node size, not decrease it. Extra small (XS) deployments limit certain services.

.Steps

. Launch ONTAP tools Manager: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Log in with your ONTAP tools administrator credentials.
. Select *Edit Appliance Settings* from the overview section.
. In the *Configuration* section, select your new node size and toggle the HA switch to enable High Availability.
. On the *HA settings* page, verify the following:

** The content library resides on the same vCenter Server where the ONTAP tools virtual machines (VMs) run.
** The ONTAP tools VMs are deployed on a cluster or resource pool, not directly on an ESXi host.
+
[IMPORTANT]
After you enable HA, you cannot revert to a non-HA single-node configuration.
. In the *HA settings* section, enter the network details for Nodes 2 and 3. ONTAP tools supports three nodes in HA mode.
+
ONTAP tools pre-fills most fields with Node 1 network settings. You can edit these values before completing the wizard. IPv6 address entries are available only if IPv6 is enabled on the management node. Ensure that each ESXi host runs only one ONTAP tools VM.
. Review the summary and click *Save*.

.Result

The appliance begins scaling and HA enablement. Monitor progress on the *Overview* page or track the job from the *Jobs* view using the job ID.

If HA deployment fails with a status of 'New', delete the failed VM in vCenter and retry.

Review the *Alerts* tab for any warnings or issues during the process.
