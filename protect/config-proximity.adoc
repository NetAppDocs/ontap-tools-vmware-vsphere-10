= Configure proximity and access for datastore protection with ONTAP tools
:icons: font
:imagesdir: ../media/

[.lead]
Configure proximity and access settings to define source and target sites, assign hosts, and pair SVMs for robust datastore protection and failover in ONTAP tools.

.Before you begin

* Verify that you have administrative privileges in vSphere.
* Ensure that the host cluster and datastores are eligible for protection.
* Review site name requirements, including character limits and allowed characters.

.Steps

. In the vSphere client, right-click the host cluster and select *Configure proximity or access*.
. In the configuration window, select the cluster configuration type: *Uniform* or *Non-uniform*.
. Enter site names for the source and target sites. Default names are "Site A" and "Site B". You can edit these fields as needed. Ensure that site names comply with character restrictions.
. Click *Next*.
. On the host assignment page, assign each host to either the source site or the target site. All hosts must be assigned, and a host cannot belong to both sites. The *Next* button is enabled after all hosts are assigned.
. Click *Next*.
. On the *Storage SVM peers* page, assign each SVM to the appropriate site. You can peer multiple SVMs, but at least one must be assigned to each site. When you assign an SVM to a site, its peer SVM is automatically assigned to the opposite site.
. Click *Next*.
. Review the *Summary* page. Confirm the source and target hosts, SVM peering, and proximity assignments.
. Click *Create* to apply the configuration.
+
NOTE: If the cluster already has a proximity configuration, an error message is displayed.

. To view or edit an existing cluster proximity configuration:
.. Go to the ONTAP tools plug-in view.
.. Navigate to *Protect* > *Cluster proximity/access*.
.. Select the cluster to view its current configuration.
.. Click the vertical ellipsis and select *Edit* to modify the configuration. The wizard displays the current settings for editing.

.Result

The configuration is applied, and you can view or edit it in the ONTAP tools plugin.
